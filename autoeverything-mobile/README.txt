AutoEverything Mobile Studio — prototype

This is a mobile-first companion prototype, not the original Chrome extension.
It supports prompt queue preparation, story metadata, character notes, local browser storage, JSON project export, and manual Google Flow handoff.
It does NOT automate Google Flow, access Google cookies, control Chrome, or include the original cloud repair/server services.

Open index.html in a modern browser. For persistent use on iPhone, host the folder on a trusted HTTPS static host and add it to the Home Screen. Local file behavior varies by browser; JSON export is recommended for backups.
